# NotoSansSC glyphs

- `0-255.pbf` and `8192-8447.pbf` are Latin/punctuation glyph ranges from
  [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets), font `Noto Sans Regular`.
- Chinese glyphs are rendered by MapLibre `localIdeographFontFamily` using the device's CJK font.
- Noto Sans is licensed under the SIL Open Font License 1.1:
  https://github.com/notofonts/noto-cjk/blob/main/LICENSE
