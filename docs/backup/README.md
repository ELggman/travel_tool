# 行程 JSON 导入/导出（无云端备份）

- 日期：2026-10-27
- 文件：`yanlu-<city>-<startDate>.json`
- 格式：

```json
{
  "trip": { "...": "Trip" },
  "exportedAt": "2026-10-27T..."
}
```

导入也接受裸 Trip（没有 `trip` 外壳）。

## 当前行为

- 导出：当前行程 + 导出时间
- 导入：
  - 校验 `days` 非空
  - 根据 `cityId` 切换城市（无效时使用当前城市）
  - 用 `normalizeTrip` 补齐字段/日期
  - 覆盖该城市当前行程
  - 回到总览并提示
  - 若该城市离线包未下载，提示“行程已导入，但该城市离线包尚未下载”

## 验证

将导出的 JSON 中 `days[0].title` 改为“导入测试标题”，通过网页文件输入导入：

```text
页面回到总览
localStorage 中 day title = 导入测试标题
```

## 限制

- 覆盖式导入，没有“合并/预览”
- 不校验业务字段（重复 Stop id、非法时间等）
- 不导入旧版 `.yanlu` 格式（尚不存在）
- 没有二维码分享
- 大文件/恶意 JSON 只做基础解析，未限制大小

## 意义

“不做线上”意味着没有云端备份。导入/导出是手机丢失、卸载、完全断网场景的最低兜底。
