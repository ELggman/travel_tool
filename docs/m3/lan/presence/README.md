# 成员 presence（正在看/编辑）

- 日期：2026-10-27
- 目的：让同行成员看到彼此当前停留在哪一天/哪个地点，减少并发覆盖

## 协议

`POST /hello` 增加：

```text
editing=<当前上下文>
```

`/members` 返回对象数组：

```json
{"ok":true,"members":[
  {"name":"房主","editing":"DAY 01 山城"},
  {"name":"阿宁","editing":"黄鹤楼"}
]}
```

- 每 3 秒心跳
- 12 秒无心跳过期
- 客户端只在有空时显示，不作为同步依据

## UI

同行页：

```text
在线 2 人
房主 · 阿宁
房主：DAY 01 山城 · 阿宁：黄鹤楼
```

- 未打开地点面板时显示当前天
- 打开 Stop 面板时显示该地点名

## 验证

Host + 浏览器 Guest：

```text
members：房主 · 阿宁
presence：房主：DAY 01 锁屏验收3 · 阿宁：<当前地点>
```

双方都能看到。

## 限制

- 只是“最后上报的上下文”，不是实时光标
- 同一成员只保留一个 editing 字段
- 不区分“正在看”和“正在编辑”
- 没有冲突预防，只提供提示
- 名称仍是客户端自报，服务端不做身份校验
- 旧客户端不发送 editing 时显示为空

## 与同步的关系

presence 不参与三向合并、不阻塞写入，只是协作提示。
