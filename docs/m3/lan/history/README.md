# 房间变更历史（审计层）

- 日期：2026-10-27
- 能力：同行页显示服务端 `/history` 最近 8 次成功写入
- 注意：**这不是完整操作日志，也不是增量 delta**

## 显示内容

- 版本号
- clientId 前 10 位
- baseVersion
- 写入时间

## 验证

Host 创建房间 v1，浏览器 Guest 加入后，同行页出现：

```text
v1  dev-ys91ff  base 0  15:12
```

## 它解决什么

- 能看到房间发生过几次写入、谁写的、基于哪个版本
- 排查“为什么被覆盖/为什么 409”
- 给后续操作日志提供 UI 入口

## 它不解决什么

- 不能回放操作
- 不能按 Day/Stop 字段合并
- 不能减少快照传输
- 不能替代 `baseVersion` + 三向合并
- clientId 不是昵称，需要额外映射才可读

## 结论

这是操作日志的审计层，不是同步协议升级。完整操作日志/增量 delta 仍需重写协议，暂未实现。
