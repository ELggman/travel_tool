# 弱网验收（延迟 + 连接丢弃）

- 日期：2026-10-27
- 目的：验证自动同步在非理想网络下不会卡死或静默丢失
- 拓扑：

```text
Android Guest -> Mac TCP proxy:8766 -> adb forward:8767 -> Android Host:8766
```

代理脚本：`/tmp/lan_proxy.js`（本机测试工具，不在仓库）

## 场景 A：600 ms 双向延迟

```text
Guest 改标题“弱网延迟同步”
Host 数秒内收到
```

## 场景 B：300 ms 延迟 + 20% 连接丢弃

```text
Guest 改标题“丢包同步”
请求可能失败并重试
Host 最终收到“丢包同步”
```

## 结论

- 轮询 + 自动重试可以跨过临时延迟/连接失败
- 没有出现静默覆盖或永久卡死
- 失败期间 UI 可能短暂显示“连接中断”，恢复后回到自动同步

## 限制

- 这是 Mac 上的 TCP 代理，不是真实蜂窝/Wi-Fi 无线链路
- 只模拟固定延迟和连接级丢弃，没有带宽限制、抖动、乱序
- 只有 2 个客户端参与本轮
- 没有测长时间断网后的批量补发
- 代理脚本不提交仓库
