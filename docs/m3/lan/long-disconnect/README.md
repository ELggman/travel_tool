# 长时间断网后的批量补发

- 日期：2026-10-27
- 拓扑：Android Host + 浏览器 Guest（adb forward）
- 目的：验证离线约 60 秒、多次修改后恢复连接，是否全部补齐

## 步骤

1. Host 创建房间 v1
2. 浏览器 Guest 加入
3. 移除 `adb forward tcp:8766`，模拟断网
4. Guest 连续修改：
   - 当天标题 → “长断网标题”
   - 第一个地点类别 → “长断网类别”
5. 保持断网 60 秒
6. 恢复 `adb forward`
7. 等待自动重试/同步

## 结果

```text
Guest 状态：gone=false，title=长断网标题
Host 总览：长断网标题
Host 地点类别：长断网类别
```

两处修改都到达 Host，没有丢失。

## 覆盖

- 断网期间本地继续编辑
- 多次修改合并为当前快照
- 恢复后自动重试
- 服务端 baseVersion 未变化时仍能补发（重连触发）

## 限制

- 60 秒，不是数小时
- 只有 2 个客户端
- 用移除 adb forward 模拟，不是真实无线断网
- 没有在断网期间让双方同时改同一字段
- 没有测大批量（几十次）操作

## 结论

当前“快照 + baseVersion + 三向合并 + 重试”能覆盖短途旅行中的短时断网；更长断网和大量离线编辑仍建议后续专项测试。
